Opinionated walkthroughs you follow once and reuse forever. Each recipe answers a "how do I X" with a specific, ordered sequence of commands — no theory, no comparison tables, no menu of options.

## What makes something a "recipe"

A recipe is:

- **Numbered steps you run in order.** Not a discussion. Not options. The right way to do this specific thing.
- **Copy-pasteable.** Every command works on its own. No `<your-name>` placeholders unless explicitly noted.
- **Decisive.** When there's a choice, the recipe picks. The reasoning is one sentence — not a comparison table.
- **Idempotent where possible.** Running it twice doesn't break things.

A recipe is NOT:

- A README (those describe; recipes prescribe)
- A tutorial (those teach; recipes execute)
- A reference (those exhaust; recipes converge)
